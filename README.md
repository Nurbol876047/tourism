# Есте сақтау жолы

ИИ-генератор маршрутов по местам «тёмного туризма» (мемориалам памяти) Казахстана.
Школьный научный проект, интерфейс — на казахском языке.

**Стек:** Python + Flask · один `index.html` · Leaflet + OpenStreetMap · OpenAI `gpt-4o-mini`.

## Структура

```
app.py            — сервер Flask (GET /, POST /api/route)
index.html        — весь фронтенд (HTML + CSS + JS)
places.json       — список объектов памяти
cities.json       — пункты отправления: города, аудандар и ауылдар ҚЗО (поиск в форме)
requirements.txt  — зависимости Python
.env              — ваш ключ OpenAI (создаётся вручную, в git не попадает)
```

## Запуск

1. Установите Python 3.9+ и создайте виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` (можно скопировать `.env.example`) и впишите ключ:

   ```
   OPENAI_API_KEY=sk-...
   ```

4. Запустите сервер:

   ```bash
   python app.py
   ```

5. Откройте в браузере http://127.0.0.1:5000

> Ключ хранится только на сервере: фронтенд обращается к `/api/route`, а запрос к OpenAI делает `app.py`.
> Для карты нужен интернет (Leaflet и тайлы OpenStreetMap подключаются через CDN).

## Как это работает

1. Пользователь заполняет форму → `index.html` отправляет `POST /api/route`.
2. `app.py` проверяет параметры, берёт из `places.json` объекты по выбранным интересам.
3. Объекты и параметры уходят в OpenAI (`response_format={"type": "json_object"}`).
4. Ответ проверяется: **id, которых нет в `places.json`, отбрасываются**; название и координаты берутся из `places.json`, а не от ИИ.
5. Браузер рисует маркеры, линию маршрута и карточки по дням.

## ⚠️ Важно: проверьте координаты вручную

Координаты в `places.json` подставлены **приблизительно, по памяти**, и **не проверены по карте**.
Особенно неточными могут быть: Спасск, АЛЖИР (Ақмол), оба алматинских ескерткіша, монумент в Астане.
Перед защитой найдите каждый объект на [OpenStreetMap](https://www.openstreetmap.org) или Google Maps
(правый клик по точке → координаты) и исправьте `lat` / `lng`.

Так же стоит проверить `visit_hours` и описания по официальным источникам музеев — часы работы могли измениться.
